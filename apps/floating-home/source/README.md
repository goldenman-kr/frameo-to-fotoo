# Floating Home 1.4 — DP103 / Android 6

로컬에서 만든 홈·뒤로가기 오버레이입니다. 광고, 인터넷 권한, 접근성 서비스를 사용하지 않습니다.

- 하나의 112×56dp 둥근 알약 배경에 왼쪽 홈, 오른쪽 뒤로가기를 표시합니다. 테두리와 가운데 구분선이 없습니다.
- 배경색은 #334658, 전체 불투명도는 25%입니다. 아이콘은 각 절반의 중앙에 직접 그립니다.
- 각 버튼의 터치 영역은 56×56dp입니다. 홈은 기본 런처로 이동하고, 뒤로가기는 이 단말에 이미 있는 su 권한으로 input keyevent 4를 실행합니다.
- 어느 쪽이든 끌어서 놓으면 버튼 묶음 중심이 속한 사분면의 화면 모서리로 이동합니다. 화면 회전 후에도 같은 모서리를 유지합니다.
- Floating Home 앱에서 켜면 다음 부팅에도 시작합니다. 끄면 서비스와 자동 시작을 끕니다. 다른 앱 위에 표시 권한이 필요합니다.
- 오버레이를 별도 전경 서비스 프로세스에서 실행합니다. 위치와 활성화 설정도 별도 파일로 저장합니다. 시스템 강제 종료나 장시간 동작까지 보장하지는 않습니다.

## 빌드

기존 Java와 Android SDK android-28, build-tools 35.0.0을 사용합니다. 외부 라이브러리나 다운로드는 없습니다.

`bash build.sh`

출력은 상위 폴더의 FloatingHome.apk입니다. 로컬 서명 키와 중간 산출물은 작업 폴더의 work/floating-home-build에 보관됩니다.

## 검증

- API 23 대상 빌드 및 APK 서명 검증
- DP103에 업데이트 설치, 오버레이 영역만 잘라 배경·중앙 정렬·테두리 제거 확인
- 사분면, 중앙선 경계, 회전, 직사각형 버튼 묶음 계산 32개 검사
- 단말에서 네 모서리로 드래그해 이동하는 동작 확인 후 원래 모서리로 복귀
- 기존 버전의 단말 뒤로가기 명령 종료 코드 0 확인; 1.4에서도 동작 코드는 동일
- 실제 기기 재부팅은 하지 않음. 사용자 0과 앱 수신기만 지정한 BOOT_COMPLETED 신호로 자동 시작 로그 확인
